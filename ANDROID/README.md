# AquaHatch สำหรับ Android / LDPlayer — 0.13.0+2014

[ดาวน์โหลด AquaHatch-v0.13.0-Android-universal.apk](https://github.com/Sivacxool/aquafish/raw/refs/heads/main/ANDROID/AquaHatch-v0.13.0-Android-universal.apk)

APK Universal รวม ARM32, ARM64 และ x86_64 สำหรับมือถือ Android และ LDPlayer รุ่นที่รองรับ

## ติดตั้ง

1. ดาวน์โหลด APK จากโฟลเดอร์นี้แล้วเปิดติดตั้ง หรือใช้ปุ่มติดตั้ง APK ใน LDPlayer
2. รุ่นนี้ใช้ลายเซ็นเดียวกับ APK 0.10.0 เดิม จึงอัปเดตทับได้โดยไม่ต้องลบข้อมูลแอป
3. เปิด **ตั้งค่า → เริ่มเชื่อมต่อบอร์ดหลัก** และเพิ่มกล้องแยกตามขั้นตอนในแอป ใช้รหัสจับคู่ของอุปกรณ์แต่ละตัว

แอปนี้เป็นชุดติดตั้งโดยตรง ยังไม่ได้เผยแพร่ผ่าน Play Store

## กล้องและ Wi-Fi

- ใช้ public CA กล้องชุดเดียวกับ iOS 0.12.0 และเฟิร์มแวร์กล้องที่แก้ล่าสุด
- รหัสจับคู่กล้องและ Wi-Fi บ้านที่บันทึกไว้ในกล้องยังคงเดิม
- APK เก่าที่ใช้ CA กล้องชุดก่อนต้องอัปเดตเป็นไฟล์นี้เพื่อใช้กับกล้องที่อัปเดตใบรับรองแล้ว
- LDPlayer ใช้เครือข่ายเสมือนของ Windows การเลือก Wi-Fi จริงต้องทำผ่านอะแดปเตอร์ของ Windows
