# โมเดลนับลูกปลา

โปรเจกต์นี้ยังไม่รวมโมเดลที่ฝึกด้วยภาพลูกปลาจริง ภาพจำลอง 48 ตัวในแอปใช้ทดลองการตรวจแก้ผลเท่านั้น

1. ถ่ายภาพถาดจริงจากด้านบน รวมตัวอย่างหลายรอบฟัก หลายระดับความหนาแน่น เงาสะท้อนและฟองน้ำ
2. กำหนดคลาสชื่อ larva และแนวทาง annotation กรณีซ้อนกัน/เห็นบางส่วนให้เหมือนกัน
3. แบ่ง train, validation, test ตามรอบฟัก/วิดีโอ ไม่แยกเฟรมคลิปเดียวกันข้ามชุด
4. ฝึก baseline ด้วย train.py และประเมินความคลาดเคลื่อนของจำนวนบนชุด test ที่ไม่ใช้ปรับโมเดล
5. ตั้ง LARVAE_MODEL_PATH ให้ชี้ best.pt และ LARVAE_CLASS_NAME=larva ใน Gateway
6. ภาพจริง/คลิปจะส่งผ่าน HTTPS ไปยัง Gateway; คลิปยาวไม่เกิน 60 วินาทีและไฟล์ไม่เกิน 50 MB
7. Gateway เลือกเฟรมคมชัดจากคลิปแล้วนับตัวที่เห็นในเฟรมนั้น ไม่รวมผลทุกเฟรม

Inference ใน Gateway เป็นเส้นทางต้นแบบแบบจำกัดหนึ่งงานพร้อมกัน ไม่ใช่ worker queue สำหรับบริการหลายเครื่อง รุ่นถัดไปต้องแยก Celery worker และทดสอบ LiteRT บนโทรศัพท์เป้าหมาย ก่อนเปิดการนับแบบ offline

ก่อนจำหน่าย/เผยแพร่แอปปิดซอร์ส ให้ตรวจเงื่อนไขใบอนุญาตของ Ultralytics และองค์ประกอบที่นำมาใช้
