# AquaHatch 0.6 — ตั้ง Wi-Fi จากแอป ใช้บอร์ดตรง

รุ่นนี้เพิ่มขั้นตอนตั้ง Wi-Fi ลงในแอปโดยตรง บอร์ด ESP32-S3 ใช้เฟิร์มแวร์ `0.6.0-local` มือถือคุยกับบอร์ดผ่าน HTTPS และใบรับรองเฉพาะเครื่อง คอมและ Gateway ไม่อยู่ในเส้นทางการใช้งานนี้

## บอร์ดที่แอปเคยเชื่อมแล้ว

1. ติดตั้ง `AquaHatch-v0.6.0-Android-universal.apk` บน Android หรือ LDPlayer
2. เปิด **ตั้งค่า → ตั้ง Wi-Fi ให้บอร์ด**
3. กด **เริ่มตั้งค่า** แอปใช้รหัสบอร์ดที่เก็บไว้และค้นหาบอร์ดจากการเชื่อมต่อเดิม
4. เลือก Wi-Fi บ้านจากรายการ 2.4 GHz ที่ ESP32 สแกนพบ ใส่รหัส หรือเลือกใช้รหัสเดิมเมื่อเป็นชื่อเครือข่ายเดิม
5. กด **ส่ง Wi-Fi ให้บอร์ด** รอให้บอร์ดยืนยัน หากข้อมูลใหม่ใช้ไม่ได้ บอร์ดจะกลับไปใช้เครือข่ายเดิม
6. เมื่อบอร์ดเชื่อมสำเร็จ ให้มือถือกลับไปใช้ Wi-Fi บ้านที่เลือก แล้วกด **ยืนยันและเข้าใช้งาน** แอปบันทึก URL รหัสเครื่อง และโหมด ESP32 ในบ้านให้เอง

## ตั้งครั้งแรก หรือเปลี่ยนเราเตอร์จนแอปหาบอร์ดเดิมไม่เจอ

1. จ่ายไฟให้บอร์ด เปิดแอป → **ตั้งค่า → ตั้ง Wi-Fi ให้บอร์ด** ใส่รหัสจับคู่จากบัตรประจำเครื่อง
2. แอปแสดง Wi-Fi **AquaHatch-117C** และรหัสสำหรับเชื่อมต่อ กดเปิดหน้าตั้งค่า Wi-Fi ของมือถือและเลือกเครือข่ายนี้
3. หากมือถือแจ้งว่าไม่มีอินเทอร์เน็ต ให้เลือกใช้งานเครือข่ายนี้ต่อ แล้วกลับมาแอป กด **เชื่อม Wi-Fi บอร์ดแล้ว ตรวจบอร์ด**
4. เลือก Wi-Fi บ้านย่าน 2.4 GHz จากรายการที่บอร์ดค้นพบ ใส่รหัส และกดส่ง
5. ระหว่างเชื่อม บอร์ดอาจเปลี่ยนช่องสัญญาณ ถ้ามือถือหลุด ให้เชื่อม AquaHatch-117C กลับแล้วกดตรวจผล
6. เมื่อสำเร็จ ให้มือถือกลับไปเชื่อม Wi-Fi บ้าน แล้วกด **ยืนยันและเข้าใช้งาน**

บัตร `DEVICE_PAIRING_PRIVATE.html` พิมพ์เก็บกับเครื่องได้ มีรหัสส่วนตัวและไม่รวมใน source ZIP สำหรับส่งต่อ รหัสจับคู่ รหัส Wi-Fi บอร์ด และรหัส Wi-Fi บ้านมีหน้าที่ต่างกัน แอปใช้ใบรับรองที่จับคู่กับบอร์ดนี้เท่านั้น

บอร์ดเปิด Wi-Fi ตั้งค่าทุกครั้งที่บูต หากเชื่อม Wi-Fi บ้านได้แล้วและไม่มีมือถือเกาะเครือข่ายตั้งค่าอยู่ จะปิดเครือข่ายตั้งค่าหลัง 10 นาที ปิดแล้วเปิดไฟเลี้ยงเพื่อเปิดอีกครั้ง แอปที่ติดต่อบอร์ดผ่านเครือข่ายบ้านได้อยู่แล้วสามารถสั่งเปิดเครือข่ายตั้งค่าได้ด้วย

ถ้าเปิดแอปขณะบอร์ดยังบูตหรือกำลังเชื่อม Wi-Fi แอปจะแสดงว่ารอเชื่อมต่อและลองใหม่เอง เมื่อบอร์ดพร้อมแล้วจะรับสถานะต่อ หากยังไม่กลับมา ให้ตรวจว่าอยู่ Wi-Fi บ้านเดียวกัน หรือเข้าเมนูตั้ง Wi-Fi ให้บอร์ดอีกครั้ง

## ขอบเขต

ใช้ไฟเลี้ยงบอร์ดตามปกติ หลังอัปเดตเฟิร์มแวร์ครั้งนี้แล้ว การตั้ง Wi-Fi ไม่ต้องต่อ USB กับคอม ในตัวจำลอง Android ใช้ตรวจแอปกับบอร์ดผ่าน LAN ได้ การสลับไป Wi-Fi จริงของบอร์ดต้องใช้มือถือ/อุปกรณ์ Wi-Fi ที่เข้าถึงคลื่นของบอร์ดได้

เซนเซอร์ กล้อง รีเลย์ ปั๊มและฮีตเตอร์ยังต้องติดตั้งและยืนยันขาต่อก่อนใช้งาน เฟิร์มแวร์รุ่นนี้ไม่ขับ GPIO ภายนอก


## ย้ายสถานที่หรือเปลี่ยนคอม

โปรแกรมและ Wi-Fi ที่บันทึกอยู่ในบอร์ด ไม่ได้ผูกกับคอมเครื่องเดิม
เมื่อไม่มี Wi-Fi เดิม ให้ปิด–เปิดไฟบอร์ด เปิดแอปและเข้าตั้ง Wi-Fi ให้บอร์ด
ใช้มือถือเชื่อม AquaHatch-117C ด้วยรหัส Wi-Fi บอร์ดจากบัตร กลับเข้าแอป
เลือกเครือข่ายใหม่ 2.4 GHz ใส่รหัสของเครือข่ายใหม่ และส่งค่า
เมื่อสำเร็จให้มือถือกลับเข้า Wi-Fi ใหม่ แล้วกดยืนยันและเข้าใช้งาน

บน LDPlayer การเปลี่ยน Wi-Fi จริงต้องทำที่ Windows เพราะเครือข่ายในตัวจำลองเป็นเครือข่ายเสมือน
การสลับ SoftAP บนมือถือจริงยังไม่ได้ตรวจในรอบทดสอบนี้

## รหัสที่ไม่อยู่ใน GitHub

บัตรจับคู่ส่วนตัว กุญแจ TLS รหัส Wi-Fi และสำเนาแฟลชไม่เผยแพร่ใน repository นี้
ผู้ใช้บอร์ดเดิมใช้บัตรส่วนตัวที่จัดไว้ให้และ APK ที่มากับบอร์ด
ผู้ประกอบบอร์ดใหม่อ่าน REBUILD.md และสร้างคู่ใบรับรองใหม่ จากนั้นสร้างทั้งเฟิร์มแวร์และแอปให้ตรงกัน
