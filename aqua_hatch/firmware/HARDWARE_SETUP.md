# ข้อมูลก่อน flash เครื่องจริง

ชุดปัจจุบันกำหนดแล้ว: ESP32-S3 + DS18B20 GPIO4 + RS-LDO-N01-2-20 ผ่าน RS485 TX16/DE17/RX18 ดูสายและผลทดสอบใน `../SENSORS_SETUP_TH.md` และเฟิร์มแวร์ `local_server`

สำหรับ pH, Flow, ระดับน้ำ และวงจรรีเลย์/โหลดที่ยังไม่ระบุ ต้องตรวจรุ่นและวงจรจริงก่อนกำหนด GPIO หรือระดับรีเลย์

| ส่วน | ข้อมูลที่ต้องกำหนด |
|---|---|
| ESP32 | รุ่นบอร์ด ชิป แรงดัน และ pinout |
| pH | รุ่นหัววัด/วงจรแปลง วิธีสื่อสาร ช่วงแรงดันเอาต์พุต วิธีสอบเทียบและบัฟเฟอร์ตามคู่มือ |
| อุณหภูมิ | รุ่น ช่วงวัด วิธีสื่อสาร และค่าที่รายงานเมื่อสายขาด |
| Flow | รุ่น ค่าพัลส์/ลิตร และช่วงวัด |
| ระดับน้ำ | เซนเซอร์และสัญญาณปกติ/น้ำต่ำ/สายขาด |
| โหลด | ปั๊ม ฮีตเตอร์ ระบบเย็น กลไกหมุนไข่ที่ติดตั้งจริง พร้อมแรงดัน/กระแส |
| รีเลย์ | Active-high/low สถานะบูตและเมื่อ ESP32 รีเซ็ต |
| เครือข่าย | Wi-Fi, MQTT TLS, device_id, credential เฉพาะเครื่อง |

ไม่มีระบบเติมออกซิเจนหรือชุดจ่ายสารปรับ pH

ก่อนต่อโหลดจริง ตรวจรีเลย์ทีละช่องกับโหลดทดสอบ ตรวจน้ำต่ำ ไม่มี flow เซนเซอร์เสีย หลุด Wi-Fi หมดเวลา Manual และไฟดับ/เปิดใหม่ เทียบค่ากับเครื่องมืออ้างอิง
ESP32 ต้องคุม Auto และเงื่อนไขป้องกันเองเมื่อมือถือ/Gateway หายไป แอปไม่ใช่วงจรตัดความร้อนอิสระ
