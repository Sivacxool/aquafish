# AquaHatch สำหรับ iPhone — 0.11.1+2012

[ดาวน์โหลด AquaHatch-v0.11.1-iOS-unsigned.ipa](https://github.com/Sivacxool/aquafish/raw/refs/heads/main/IOS/AquaHatch-v0.11.1-iOS-unsigned.ipa)

ไฟล์นี้เป็นแอป iOS arm64 สำหรับ iPhone จริง รองรับ iOS 13 ขึ้นไป และยังไม่เซ็น ต้องเซ็นก่อนติดตั้ง เปิดไฟล์จาก Safari เพื่อติดตั้งตรง ๆ ไม่ได้

## ติดตั้งจาก Windows

1. ใช้ [Sideloadly จากเว็บไซต์ผู้พัฒนา](https://sideloadly.io/) แล้วเสียบ iPhone กับคอม ปลดล็อกและเชื่อถือคอมพิวเตอร์
2. เลือก IPA 0.11.1 จากโฟลเดอร์นี้ เลือก iPhone แล้วติดตั้งด้วย Apple ID ของเจ้าของ กรอกข้อมูลบัญชีและรหัสยืนยันในโปรแกรมด้วยตนเอง
3. หากเคยลงรุ่นก่อน ให้ติดตั้งด้วย Apple ID และ bundle identifier เดิมเพื่ออัปเดตทับ ไม่ต้องลบแอปก่อน
4. เปิด AquaHatch อนุญาตเครือข่ายเฉพาะที่ แล้วเชื่อม Wi-Fi ตามขั้นตอนที่แอปแสดง
5. เพิ่มกล้องด้วยรหัสจับคู่ของกล้องเดิม แล้วทดสอบรับภาพ

[คู่มือละเอียดและข้อจำกัด Apple ID ธรรมดา](../IOS_INSTALL_TH.md)

## สถานะการทดสอบ

- Native IPA arm64, การเปิดแอปใน iPhone Simulator และการตรวจใบรับรองด้วยระบบ Apple ผ่าน
- ผู้ใช้ยืนยันว่าเพิ่มกล้อง ESP32-CAM บน iPhone หลังติดตั้ง 0.11.1 สำเร็จ
- ยังไม่ได้ยืนยันการถ่ายภาพบน iPhone แยกจากผลเพิ่มกล้อง
- ใช้ใบรับรองกล้องใหม่ 730 วัน ต้องอัปเดตเฟิร์มแวร์กล้องให้ตรงกับแอปนี้
- S3 ที่ยังใช้ใบรับรองเซิร์ฟเวอร์ 10 ปีต้องต่ออายุแยก; การแก้ครั้งนี้ทำกับกล้อง
