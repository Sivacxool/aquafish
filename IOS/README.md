# AquaHatch สำหรับ iPhone — 0.13.0+2014

[ดาวน์โหลด AquaHatch-v0.13.0-iOS-unsigned.ipa](https://github.com/Sivacxool/aquafish/raw/refs/heads/main/IOS/AquaHatch-v0.13.0-iOS-unsigned.ipa)

ไฟล์นี้เป็นแอป iOS arm64 สำหรับ iPhone จริง รองรับ iOS 13 ขึ้นไป และยังไม่เซ็น ต้องเซ็นก่อนติดตั้ง เปิดไฟล์จาก Safari เพื่อติดตั้งตรง ๆ ไม่ได้

## ติดตั้งจาก Windows

1. ใช้ [Sideloadly จากเว็บไซต์ผู้พัฒนา](https://sideloadly.io/) แล้วเสียบ iPhone กับคอม ปลดล็อกและเชื่อถือคอมพิวเตอร์
2. เลือก IPA 0.13.0 จากโฟลเดอร์นี้ เลือก iPhone แล้วติดตั้งด้วย Apple ID ของเจ้าของ กรอกข้อมูลบัญชีและรหัสยืนยันในโปรแกรมด้วยตนเอง
3. หากเคยลงรุ่นก่อน ให้ติดตั้งด้วย Apple ID และ bundle identifier เดิมเพื่ออัปเดตทับ ไม่ต้องลบแอปก่อน
4. เปิด AquaHatch อนุญาตเครือข่ายเฉพาะที่ แล้วเชื่อม Wi-Fi ตามขั้นตอนที่แอปแสดง
5. เพิ่มกล้องด้วยรหัสจับคู่ของกล้องเดิม แล้วทดสอบรับภาพ

[คู่มือละเอียดและข้อจำกัด Apple ID ธรรมดา](../IOS_INSTALL_TH.md)

## สถานะการทดสอบ

- Native IPA arm64, การเปิดแอปใน iPhone Simulator และการตรวจใบรับรองด้วยระบบ Apple ผ่าน
- ผู้ใช้เคยยืนยันเพิ่มกล้องบน iPhone ด้วย 0.11.1; รุ่น 0.12.0 / OV3660 ยังต้องทดสอบบน iPhone หลังติดตั้ง
- ยังไม่ได้ยืนยันการถ่ายภาพบน iPhone แยกจากผลเพิ่มกล้อง
- ใช้ใบรับรองกล้องใหม่ 730 วัน ใช้ร่วมกับเฟิร์มแวร์กล้อง OV3660 0.12.0-camera.1 ที่เคยลงไว้ได้ รุ่น 0.13.0 ไม่ได้แฟลชกล้องเพิ่ม
- S3 ที่ใช้ใบรับรองเก่า 10 ปี ต้องลงเฟิร์มแวร์ S3 ชุดใหม่ที่เตรียมใบรับรอง 730 วันไว้แล้วด้วย CA เดิม รอบนี้ยังไม่ได้อัปโหลด
